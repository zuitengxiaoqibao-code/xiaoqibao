# 新手研判台精简与数据补全设计

## 目标

把当前按部门和内部系统组织的量化平台，收敛成面向新手的 A 股观察工具。用户选择股票后，系统自动补齐可获得的数据，并优先给出可理解、可追溯的行动结论，而不是展示大量内部模块、模拟账户或不可用卡片。

本阶段不连接券商，不执行真实交易，也不保留模拟资金、模拟账户、模拟委托和模拟成交能力。

## 用户可见信息架构

主导航仅保留：

1. 今日研判
2. A 股观察
3. 新闻热点
4. 风险提醒
5. 历史复盘
6. 数据设置

可转债继续作为独立资产入口存在，不与 A 股研判、候选、风险或历史状态混合。

中书省、吏部、户部、东厂、礼部、兵部、尚书省、刑部、工部不再作为用户可见导航和页面标题。必要的风险、合规、数据与审计能力作为后台服务保留，并使用普通中文名称呈现。

## 删除范围

彻底删除以下模拟交易能力：

- 前端模拟交易与资金台账页面、组件、API 客户端和测试
- 模拟账户、持仓、现金、订单和成交相关后端路由与服务装配
- 仅服务于模拟委托的资金预算和执行代码
- 应用启动时的模拟交易数据库初始化
- 导航、文案、类型和样式中的模拟交易入口

历史数据库文件不主动破坏性删除，但新版本不再读取、写入或迁移这些模拟交易表。

## 自动数据补全

选择一只已验证 A 股后，前端先请求现有驾驶舱快照。后端根据数据覆盖情况触发幂等补全流程，并返回补全状态：

- 实时行情与估值：腾讯行情
- 日线与趋势：优先通达信或现有稳定日线源，失败时使用百度 K 线回退
- 基本面：通达信财务快照
- 新闻与个股事件：现有新闻采集与本地冻结事件仓储
- 热点与行业：从已接入的公开热点、行业或规范化新闻标签中生成
- 风险：基于行情、日线、基本面和规范化事件的确定性规则

补全任务必须设置超时、来源优先级和失败原因，不得因单一来源失败阻塞整个研判。请求期间显示“正在补齐数据”，完成后自动重新研判。相同股票、交易日和数据版本的重复请求必须幂等，并遵守历史 cutoff，不能把未来数据带入历史研判。

本阶段不伪造资金流。原 `funds` 分区从核心研判和默认界面移除，直到真实资金数据源完成接入。回测不再作为每只股票的必需分区；只有存在真实回测结果时才在历史复盘中展示。

## 新手行动卡

首屏只给出三种行动：

- 暂不参与：核心行情或趋势证据不足，需要等待数据或信号
- 加入观察：数据达到最低研判要求，未发现确定性风险阻断
- 回避：存在明确风险事件、异常波动、显著回撤或规则阻断

行动卡必须包含：一句话结论、置信度、三个以内主要依据、三个以内主要风险、需要等待的信号、重新判断条件、数据时间和来源覆盖率。

行动卡不提供买入价、卖出价、仓位、止损或模拟委托。它是观察与风险提示，不构成投资建议。

确定性规则拥有行动结论。AI 只能补充通俗解释、新闻影响、热点归因、不确定性和反方观点，不得改变行动、置信度、数字或风险门禁。

## 页面结构

### 今日研判

首屏顺序：股票选择器、数据补全状态、新手行动卡、盘前/盘中/盘后三阶段摘要、主要证据与风险。内部版本号、部门名和完整技术分区默认隐藏。

### A 股观察

展示自选股与候选股，每行只保留股票、当前行动、置信度、主要理由、数据新鲜度和变化标记。选择任意股票进入同一研判流程。

### 新闻热点

按全市场、当前股票和行业切换，明确来源、时间、关联对象和核验状态。未核验内容不得进入确定性行动依据。

### 风险提醒

按严重程度展示事件风险、数据风险和市场风险，并说明影响对象与失效时间。后台风控规则不再用部门页面暴露。

### 历史复盘

按日期查看盘前、盘中、盘后结论变化、当时可见证据和事后验证。只读取截止时间内可见的数据。

### 数据设置

展示各数据源连接状态、最后成功时间、失败原因、手动重试和自动同步开关。提供本地 AI 配置：兼容 API 地址、模型与密钥。密钥仅写入本地受忽略配置，不进入 Git、日志或 API 响应；前端读取时只显示是否已配置和脱敏尾部。

## 错误与空状态

默认页面不再平铺十个分区的“不可用”。核心数据缺失时，行动卡显示“暂不参与”和具体下一步；详细来源错误进入可展开的数据状态区域。

外部数据源失败时保留上次成功快照并标记陈旧。没有成功快照时明确说明哪个数据缺失、系统是否正在重试、用户是否需要处理配置。

AI 未配置或失败时，确定性行动卡继续可用，并在数据设置中给出配置入口。

## 安全与边界

- 不连接真实券商，不创建订单
- 不生成或展示模拟资金与模拟委托
- 不把未核验新闻作为确定性依据
- 不用 AI 填补缺失数值或改变行动结论
- A 股和可转债使用独立路由、选择状态和数据契约
- 历史请求全链路携带 cutoff

## 验收标准

- 模拟交易前后端入口与运行时服务全部移除
- 主导航只出现六个新手入口和独立可转债入口
- 任意已验证 A 股会触发幂等数据检查与补全
- 数据补全成功后自动重新研判，不要求用户理解内部部门
- 默认首屏不再出现资金未接入、回测未运行等无效卡片
- 行动卡只输出暂不参与、加入观察或回避，并包含原因、风险和等待条件
- AI 配置可在本地安全保存，未配置时不影响确定性结论
- 历史 cutoff、A 股/可转债隔离、桌面与手机布局均通过测试
- 后端、前端、构建、乱码扫描和浏览器控制台检查全部通过
