# V1 实施路线图

> 历史路线说明：本文件保留早期实施记录。涉及模拟资金、账户、订单、成交、价位、仓位或模拟操作计划的内容，已被 2026-07-16 新手驾驶舱收敛方案废止；当前产品边界以根目录 `README.md` 和 `docs/roadmap.md` 为准。

## 2026-07-16 进度

- 已交付三阶段决策查询与手动调度 API，以及根路由决策工作台。
- 已交付聚合轮询、请求隔离、历史阶段切换和模拟计划完整门禁。
- 盘中聚合现物化跨阶段当前观察状态，并保留独立版本化变化流；实际轮询退避状态来自持久化 PollState。
- 决策 SQLite 已纳入备份清单和仓储级恢复校验。
- 已交付单股决策驾驶舱、A 股候选/代码或名称搜索、本地自选、全局 `symbol` 深链和分区降级展示；可转债不读取 A 股选择。
- 已交付任意已验证 A 股的确定性即时研判。候选交易层继续由三阶段账本和行情、合规、证据、风险四项门禁授权；非候选不生成模拟价位或仓位。
- 已接入可选的 OpenAI 兼容解释网关；只有 `QIBAO_AI_BASE_URL`、`QIBAO_AI_API_KEY`、`QIBAO_AI_MODEL` 全部配置时才请求模型。未配置或调用失败不会清空确定性研判，仓库不声明任何环境已经配置 AI。
- V1 仍在实施：单股驾驶舱浏览器验收和最终生产审计继续保留在后续范围。

## 当前已实现

1. 工程底座、资产域隔离、情报指挥中枢界面。
2. 腾讯真实 A 股快照、三分钟时效检查、SQLite 审计。
3. mootdx 主源、百度备用源、DuckDB/Parquet 历史日线平台。
4. 工部历史同步 API 与状态面板。
5. 固定双均线回测、次日成交、佣金、滑点、涨跌停约束和绩效指标。
6. 中书省回测 API 与新手结果面板。
7. A 股单股决策驾驶舱、十个确定性数据分区和三阶段标的过滤。
8. 候选、搜索、自选与 URL 统一选择，以及新闻、风险、合规、审计、回测工作区深链。
9. 任意已验证 A 股即时研判、候选模拟方案门禁和 AI 解释失败降级。

## 原顺序原因

模拟交易先落地，才能持续验证研究与回测是否在真实时间序列中有效；随后建立完整风险和审计，作为任何更强信号的门槛。可转债在通用账户和风险基础稳定后接入。新闻 AI 最后接入，避免语言模型输出先于量化和风控底座。

## V1 最终验收

- 盘前、盘中、盘后流程能够按交易日运行并恢复失败任务。
- A 股与可转债页面、模型、因子和候选池完全隔离。
- 模拟账户可持续记录，现金、持仓、订单和成交能够对账。
- 所有建议、模拟指令和 AI 解释可还原当时证据。
- 回测包含成本、成交约束、样本外结果和未来数据泄漏检查。
- 数据源或模型不可用时明确降级，不使用虚构数据。
